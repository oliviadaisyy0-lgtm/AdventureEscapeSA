# Project Name : Adventure Escape SA

# Task 2 : Website Development
This website is developed as part of Task 2 for our group assignment. The purpose of the project is to create a user-friendly website with clear navigation, organised information, and a consistent design.

The website is developed using HTML and is based on the high-fidelity wireframes created in Figma.

## Project Objectives

* Develop a website based on the Figma designs.
* Provide clear and easy-to-use navigation.
* Present information in a simple and organised way.
* Create the required website pages.
* Collaborate as a group using GitHub.

## Website Pages

The website includes the following pages:

1. **Home Page (`index.html`)** – Introduces the project and provides access to the main sections of the website.
2. **About Us (`about.html`)** – Provides information about the organisation, its background, and its purpose.
3. **Contact Page (`contact.html`)** – Provides contact information and a way for visitors to make enquiries.
4. **Fees Page (`fees.html`)** – Displays relevant fees or pricing information.
5. **Individual Page** – Provides additional information about a selected service, activity, or offering.

## Technologies Used

* HTML5 – Structures the website content.
* CSS3 – Styles the website and controls its layout.
* JavaScript – Adds interactivity where required.
* Visual Studio Code – Used to write and edit the code.
* Figma – Used to design the high-fidelity wireframes.
* GitHub – Used for version control and group collaboration.

## How to Run the Website

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code.
5. Use the navigation links to explore the website pages.

## Project Design

The website design follows the high-fidelity wireframes created in Figma. The layout, colours, images, logos, and content are intended to provide a consistent user experience.
